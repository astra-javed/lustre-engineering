# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, technically rigorous environment. Treat contributors with respect, assume good intent, and focus criticism on ideas, code, and evidence rather than people.

## Expected behavior

- Be respectful and constructive.
- Welcome questions from different experience levels.
- Prefer evidence, reproducible tests, and clear technical reasoning.
- Accept corrections gracefully.

## Unacceptable behavior

Harassment, discrimination, personal attacks, intimidation, doxxing, or deliberately disruptive behavior are not acceptable.

## Reporting

For conduct concerns, contact the repository owner through the contact mechanisms provided by the GitHub repository profile. For security vulnerabilities, follow `SECURITY.md` instead.
